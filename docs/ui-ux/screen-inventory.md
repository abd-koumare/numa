# Inventaire directeur des écrans NUMA

Cet inventaire couvre la vision complète du cahier des charges. Un identifiant reste stable pendant toute la conception afin de relier parcours, maquette, prototype, tests et validation.

| Module | Écrans et états à concevoir |
|---|---|
| Identité | `ID-01` Connexion SSO, `ID-02` MFA, `ID-03` accès refusé, `ID-04` session expirée, `ID-05` profil et préférences |
| Shell | `SH-01` navigation desktop, `SH-02` navigation mobile, `SH-03` recherche globale, `SH-04` notifications |
| Accueil | `AC-01` tableau de bord, `AC-02` mes tâches, `AC-03` mes validations, `AC-04` activité récente |
| Registres | `LI-01` catalogue des listes, `LI-02` choix d’instance, `LI-03` vue tabulaire, `LI-04` vue groupée, `LI-05` vue personnelle, `LI-06` archives |
| Éléments | `EL-01` création, `EL-02` détail, `EL-03` modification, `EL-04` brouillon, `EL-05` soumission, `EL-06` annulation, `EL-07` historique, `EL-08` relations |
| Courrier | `CO-01` registre Interne, `CO-02` registre Externe, `CO-03` fiche courrier, `CO-04` bascule annuelle, `CO-05` réouverture justifiée |
| Recherche | `RE-01` résultats globaux, `RE-02` recherche dans une liste, `RE-03` filtres avancés, `RE-04` recherche par numéro |
| Import/export | `IE-01` choix fichier, `IE-02` aperçu/mapping, `IE-03` validation, `IE-04` rapport d’erreurs, `IE-05` confirmation, `IE-06` export |
| Documents | `DO-01` pièces jointes, `DO-02` aperçu, `DO-03` versions, `DO-04` métadonnées, `DO-05` erreur ou fichier refusé |
| Workflow | `WF-01` tâches, `WF-02` validation, `WF-03` rejet motivé, `WF-04` délégation, `WF-05` suivi du processus |
| Signature | `SI-01` validation électronique, `SI-02` signature graphique, `SI-03` signature numérique, `SI-04` résultat et preuve |
| List Builder | `LB-01` assistant de création, `LB-02` paramètres, `LB-03` champs, `LB-04` formulaire, `LB-05` vues, `LB-06` cycle/instances, `LB-07` permissions, `LB-08` publication |
| Field/Form Builder | `FB-01` catalogue de champs, `FB-02` propriétés, `FB-03` mise en page, `FB-04` conditions, `FB-05` calculs/relations, `FB-06` aperçu/erreurs |
| Numbering Builder | `NB-01` format, `NB-02` variables, `NB-03` portée/compteur, `NB-04` simulation, `NB-05` numéros annulés |
| Rule Builder | `RB-01` catalogue, `RB-02` éditeur SI/ALORS, `RB-03` test de règle, `RB-04` erreurs/conflits, `RB-05` versions |
| Workflow Builder | `WB-01` catalogue, `WB-02` diagramme, `WB-03` état/transitions, `WB-04` acteurs, `WB-05` conditions/actions, `WB-06` test/publication |
| Page Builder | `PB-01` catalogue, `PB-02` éditeur, `PB-03` composants, `PB-04` propriétés/visibilité, `PB-05` aperçu responsive, `PB-06` versions/publication |
| Templates | `TE-01` catalogue, `TE-02` création depuis template, `TE-03` détail/version, `TE-04` publication, `TE-05` copie de configuration |
| Administration | `AD-01` site/thème, `AD-02` navigation, `AD-03` utilisateurs, `AD-04` groupes, `AD-05` rôles, `AD-06` permissions fines, `AD-07` paramètres système |
| Audit | `AU-01` journal, `AU-02` détail événement, `AU-03` comparaison avant/après, `AU-04` filtres/export |
| Sauvegardes | `BA-01` tableau de bord, `BA-02` création, `BA-03` détail/statut, `BA-04` rétention, `BA-05` restauration sécurisée, `BA-06` résultat/échec |
| Exploitation | `OP-01` état des services, `OP-02` stockage, `OP-03` alertes, `OP-04` intégrations/webhooks, `OP-05` documentation API |
| Système | `SY-01` chargement, `SY-02` état vide, `SY-03` erreur, `SY-04` accès interdit, `SY-05` confirmation destructive, `SY-06` hors ligne |
